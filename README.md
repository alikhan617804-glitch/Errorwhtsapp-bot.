# ERROR 💀 WhatsApp Bot

Fresh ERROR-branded multi-device WhatsApp bot project.

## Features
- 400+ commands/features
- Group moderation, anti-link, anti-spam and anti-flood
- AI and utility tools
- Media, sticker and downloader tools
- Admin/owner controls
- Status automation
- Customizable prefix, theme and settings
- Official ERROR 💀 updates channel

```bash

npm start
```

Use `.menu` to view commands and `.channel` / `.updates` for the official channel.
